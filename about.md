# ZMenu7

A customizable mod menu for Geometry Dash.

## How to use
1. On PC, press `TAB` to open or close the menu.
2. Enable or configure the features you want to use.
3. For help and support, open an issue or join the [Support Discord server](https://discord.gg/NnpwFRDMND).

## Features
- 90+ gameplay and utility features
- Start Position Switcher
- Customizable labels
- Trajectory display
- Internal recorder
- Replay bot
- Configurable keybinds
- Customizable themes
